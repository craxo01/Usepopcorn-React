این پروژه یک اپلیکیشن مدیریت و جستجوی فیلم است که با استفاده از React ساخته شده است.

در این پروژه می‌توانید فیلم موردنظر خود را جستجو کرده و اطلاعاتی مانند امتیاز، بازیگران و سایر جزئیات فیلم را مشاهده کنید. همچنین امکان امتیازدهی به فیلم‌ها و اضافه کردن آن‌ها به Watchlist وجود دارد.

فیلم‌های ذخیره‌شده و امتیازهای کاربر در Local Storage مرورگر ذخیره می‌شوند تا اطلاعات حتی پس از بستن و باز کردن مجدد صفحه نیز باقی بمانند.
